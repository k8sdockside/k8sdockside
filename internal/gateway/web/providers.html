Where each provider registers apps
  • GitHub: Settings → Developer settings → OAuth Apps → New OAuth App.
  • Google: Google Cloud console → APIs & Services → Credentials → Create OAuth client ID, of type web application.
  • Facebook: developers.facebook.com → My Apps → Create App, then add Facebook Login.
  • GitLab: Preferences → Applications, with the openid, email and profile scopes.
  • Microsoft: Microsoft Entra admin center → App registrations → New registration, with a web redirect URI.
  • OpenID Connect: Keycloak, Dex, Authentik, Okta, Zitadel and the like — give the issuer URL.

An account is matched to a user here by the email address the provider vouches for. Microsoft does not vouch for addresses, so Microsoft users either join on their own, or sign in once and are then made administrators here.
